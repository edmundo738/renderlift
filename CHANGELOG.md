# Changelog

## 0.1.0

- Established RenderLift as the product name and ALRR as the internal reconstruction engine.
- Added portable resolution and dynamic-resolution core.
- Added D3D9/D3D10/D3D11/D3D12/Vulkan backend scaffolds.
- Added GTA V and Intel UHD 620 profiles.
- Added initial HLSL and GLSL spatial reference shaders.
- Added a CLI demonstration and core tests.
